# PrintCraft Web on GitHub Pages

This repository builds the official open-source [PrintCraft](https://github.com/storytold/printcraft) WebAssembly app and publishes the static web build to GitHub Pages.

Upstream source: https://github.com/storytold/printcraft

The deployment workflow tracks the upstream `main` branch. PrintCraft's web build uses relative asset URLs, so it can run from the GitHub Pages project path:

`https://appbuilderlee2.github.io/printcraft-web/`
